## Tier 1 — Deep Datasheet Technical Specifications

### 1. Programmable Logic & Processing Core

#### 1.1 Lattice LFXP3C (Main Board FPGA)
* **Family:** LatticeXP Non-Volatile FPGA
* **Logic Density:** $3,000$ 4-input Look-Up Tables (LUT4s)
* **Embedded Memory:** $54\text{ Kb}$ Distributed RAM, $54\text{ Kb}$ sysMEM Block RAM
* **Maximum Clock Frequency:** Up to $320\text{ MHz}$
* **Clock Management:** $2$ On-chip Phase-Locked Loops (PLLs)
* **Configuration Modes:** Master SPI, Slave SPI, IEEE 1149.1 JTAG
* **Key Feature:** Combines internal Flash memory with SRAM logic cells, enabling instant-on operation ($< 1\text{ ms}$) without external configuration boot latency.
* **System Role:** Serves as the central real-time system controller on the Main Board, running hardware timing engines, motor pulse generation, and parallel bus routing.

#### 1.2 Lattice LCMXO1200C (HMI Board FPGA)
* **Family:** MachXO Instant-On Programmable Logic Device (PLD)
* **Logic Density:** $1,200$ LUT4s
* **Embedded Memory:** $256\text{ Kb}$ On-chip Flash, $12\text{ Kb}$ sysMEM Block RAM
* **Operating Core Voltage:** $V_{CC} = 3.3\text{V}$ ("C" series)
* **Low-Power Modes:** Active Sleep Mode with standby current $< 100\ \mu\text{A}$
* **System Role:** Acts as glue logic on the HMI board, bridging the ARM CPU host memory bus to the LCD interface, touch panel controls, and system state monitors.

#### 1.3 Lattice LCMXO2-7000HC (Racking Board FPGA)
* **Family:** MachXO2 High-Performance Low-Power FPGA
* **Logic Density:** $6,864$ Logic Elements / LUT4s
* **Embedded Memory:** $240\text{ Kb}$ sysMEM Block RAM, $54\text{ Kb}$ User Flash Memory (UFM)
* **Hardened IP Blocks:** Integrated SPI, $\text{I}^2\text{C}$, and Timer/Counter IP blocks embedded in silicon
* **Max Available I/O:** $206$ User I/O pins
* **System Role:** Manages racking actuator sequencing and handles hardware serial communication (`SIO/SK/SE/SO`) directly via its hardened SPI/I²C peripheral blocks.

#### 1.4 Samsung S3C2440A (HMI Main Processor)
* **Core Architecture:** ARM920T 32-Bit RISC Processor
* **Maximum Operating Frequency:** Up to $400\text{ MHz}$
* **Internal Caches:** $16\text{ KB}$ Instruction Cache, $16\text{ KB}$ Data Cache, MMU
* **Integrated Peripherals:** 
  * TFT/STN LCD Controller (up to 24-bit color depth)
  * NAND Flash bootloader controller
  * 3-Channel UART, 2-Channel SPI, 1-Channel $\text{I}^2\text{C}$
  * 4-Channel DMA, 130 General Purpose I/O (GPIO) lines
* **System Role:** Primary host CPU running high-level system software, user interface rendering, and main system command state machines.

### 2. Motor Driver & Analog Signal Chains

#### 2.1 Texas Instruments DRV8818 (Main Board ×6)
* **Function:** Integrated Microstepping Bipolar Stepper Motor Driver
* **Supply Voltage Limits:** $8\text{V}$ to $35\text{V}$ continuous ($37\text{V}$ absolute maximum)
* **Output Current Capability:** $2.5\text{A}$ peak winding current per channel
* **Microstepping Indexer:** Full, 1/2, 1/4, and 1/8 step modes
* **Winding Current Formula:**
  Peak full-scale output current $I_{FS}$ is governed by the external reference voltage $V_{REF}$ and current-sense resistor $R_{SENSE}$:
  $$I_{FS} = \frac{V_{REF}}{8 \times R_{SENSE}}$$
* **Protection Circuits:** Overcurrent Protection (OCP), Thermal Shutdown (TSD), and Undervoltage Lockout (UVLO).
* **System Role:** Drives all 6 main axis stepping motors under indexer pulses generated by the Main FPGA.

#### 2.2 Texas Instruments TLC5620 (Main Board DAC)
* **Architecture:** Quad 8-Bit Digital-to-Analog Converter (DAC)
* **Interface:** 11-Bit Serial Synchronous Data Input (`CLK`, `DATA`, `LOAD`/`LDAC`)
* **Output Buffer:** 4 Independent Voltage Outputs with programmable $1\times$ or $2\times$ output scaling
* **Settling Time:** $10\ \mu\text{s}$ maximum to within $\pm 0.5\text{ LSB}$
* **System Role:** Synthesizes variable analog output voltages ($V_{REF}$) supplied to the DRV8818 stepper drivers to dynamically modulate motor current and torque.

### 3. Isolated Communication & Line Transceivers

#### 3.1 Texas Instruments AM26LV31 (HMI ×3, Main ×1)
* **Type:** Quad Low-Voltage Differential Line Driver (RS-422)
* **Supply Voltage:** $3.0\text{V}$ to $3.6\text{V}$ ($3.3\text{V}$ nominal)
* **Data Rate:** Maximum switching frequencies $> 32\text{ MHz}$
* **Propagation Delay:** $< 8\text{ ns}$ typical
* **System Role:** Converts $3.3\text{V}$ single-ended logic signals to differential RS-422 pairs for inter-board communications.

#### 3.2 Texas Instruments AM26LV32 (All Boards)
* **Type:** Quad Low-Voltage Differential Line Receiver (RS-422)
* **Common-Mode Input Voltage:** $\pm 7\text{V}$
* **Receiver Sensitivity:** $\pm 200\text{ mV}$ differential threshold
* **Failsafe Features:** Open-circuit, short-circuit, and terminated idle failsafe
* **System Role:** Converts incoming differential RS-422 signals back into single-ended $3.3\text{V}$ logic levels.

#### 3.3 Texas Instruments AM26LS31 (Racking Board)
* **Type:** Quad High-Speed Bipolar Line Driver (5V RS-422)
* **Operating Voltage:** $4.75\text{V}$ to $5.25\text{V}$ ($5\text{V}$ nominal)
* **Asymmetric Pair Rationale:** Drives higher voltage swing ($5\text{V}$) differential signals across noisy, high-EMI long-distance cable harnesses connecting to the Racking assembly.

### 4. Optocouplers & Signal Isolation

#### 4.1 Everlight 6N137 / EL6N137 (HMI ×2, Racking ×8)
* **Type:** $10\text{ Mbps}$ High-Speed Logic Gate Output Optocoupler
* **Input/Output Isolation:** $5000\text{ V}_{\text{RMS}}$
* **Common-Mode Transient Immunity (CMTI):** Minimum $10\text{ kV}/\mu\text{s}$
* **Internal Structure:** GaAsP LED optically coupled to an integrated high-gain detector with an internal open-collector NMOS output.
* **Propagation Delay:** Maximum $75\text{ ns}$ ($t_{PHL} / t_{PLH}$)
* **System Role:** Pass-through for high-frequency PWM and fast direction/step pulse signals across isolated domain barriers.

#### 4.2 Cosmo 357NT / KPC357NT (Main ~37, Racking ×3)
* **Type:** 4-Pin Mini-Flat Transistor Output Optocoupler
* **Current Transfer Ratio (CTR):** $130\%$ to $260\%$ at $I_F = 5\text{ mA}$
* **Isolation Voltage:** $3750\text{ V}_{\text{RMS}}$
* **Switching Speed:** $t_r = 5\ \mu\text{s}$, $t_f = 4\ \mu\text{s}$
* **System Role:** Isolates low-frequency control lines, including end-stop sensors, safety limit triggers, status interlocks, and relay switches.

### 5. Network, Power & Discrete Semiconductors

#### 5.1 Davicom DM9000A / DM9000AEP (HMI Board Network)
* **Type:** 10/100M Fast Ethernet Controller with MAC, PHY, and $16\text{ KB}$ SRAM
* **Bus Architecture:** 8-bit, 16-bit, or 32-bit SRAM-like parallel host interface
* **Features:** Hardware TCP/UDP/IP checksum offloading, HP Auto-MDIX, $3.3\text{V}$ supply with $5\text{V}$ tolerant I/O
* **System Role:** Provides physical Ethernet connectivity mapped into the ARM9 memory space.

#### 5.2 MaxLinear / Sipex SPX29302 (HMI Power)
* **Type:** $3\text{A}$ Low Dropout (LDO) Linear Regulator
* **Dropout Voltage:** $450\text{ mV}$ typical at $I_{OUT} = 3\text{A}$
* **Output Accuracy:** $\pm 1.0\%$
* **Thermal Loss Formula & Calculation:**
  For $V_{IN} = 5.0\text{V}$, $V_{OUT} = 3.3\text{V}$, and $I_{LOAD} = 2.5\text{A}$:
  $$P_{DISS} = (V_{IN} - V_{OUT}) \times I_{LOAD}$$
  $$P_{DISS} = (5.0\text{V} - 3.3\text{V}) \times 2.5\text{A} = 4.25\text{ W}$$
* **System Role:** Provides regulated local power to the 3.3V system rails on the HMI board.

#### 5.3 UTC TL494 (HMI Power)
* **Type:** Pulse-Width-Modulation (PWM) Power Supply Control Circuit
* **Operating Frequency:** $1\text{ kHz}$ to $300\text{ kHz}$
* **Features:** Built-in $5.0\text{V}$ reference output ($\pm 5\%$), dual error amplifiers, programmable dead-time control, uncommitted push-pull output transistors.
* **System Role:** Core PWM switching regulator controller for on-board DC-DC supply generation.

#### 5.4 HongFa HFD23/005-1ZS (Main Board Relay)
* **Type:** Subminiature DIP Signal Relay (1 Form C / SPDT)
* **Coil Voltage:** $5\text{VDC}$ ($150\text{ mW}$ nominal power)
* **Contact Rating:** $1\text{A}$ @ $125\text{VAC}$, $2\text{A}$ @ $30\text{VDC}$
* **Switching Times:** Operate time $\le 5\text{ ms}$, Release time $\le 3\text{ ms}$
* **System Role:** Hardwired mechanical safety isolator and power interlock.

#### 5.5 Alpha & Omega AO4606 (HMI Switching)
* **Type:** Complementary Dual N-Channel and P-Channel MOSFET (SOIC-8)
* **N-Channel Specs:** $V_{DS} = 30\text{V}$, $I_D = 6.9\text{A}$, $R_{DS(ON)} < 28\text{ m}\Omega$
* **P-Channel Specs:** $V_{DS} = -30\text{V}$, $I_D = -6\text{A}$, $R_{DS(ON)} < 35\text{ m}\Omega$
* **System Role:** Integrated high-side/low-side load switch driving display backlights or solenoid rails.

#### 5.6 FU120N / IRFU120N (HMI MOSFET)
* **Type:** N-Channel Power MOSFET (TO-251 / TO-252)
* **Ratings:** $V_{DS} = 100\text{V}$, $I_D \approx 9.4\text{A}$, $R_{DS(ON)} \approx 180-210\text{ m}\Omega$
* **System Role:** High-voltage discrete load switch on secondary power channels.

## Tier 3 — Confirmed Power Assemblies

### Mean Well NES-350-27 (Main System Power)
* **Output Voltage:** $27\text{VDC} \pm 1.0\%$
* **Output Rated Current:** $13.0\text{A}$
* **Total Rated Power:** $351\text{W}$
* **Input Voltage:** Range selected by switch ($90-132\text{VAC}$ / $180-264\text{VAC}$)
* **System Design Compatibility:** The **27V** system rail provides safe operating voltage headroom below the $35\text{V}$ maximum limits of the DRV8818 drivers, preserving margin against inductive back-EMF spikes generated during high-speed motor deceleration.
