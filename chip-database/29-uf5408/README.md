## What it is

An ultrafast recovery rectifier diode, sitting in series with the DC input
path on this board.

## Key specs

| Parameter | Value |
|---|---|
| VRRM (repetitive peak reverse voltage) | 1000 V |
| IFAV (max average forward current) | 3.0 A |
| IFSM (peak forward surge, 50 Hz) | 100 A |
| Reverse recovery time (trr) | ~75 ns |
| Junction temp range | −50°C to +175°C |
| Storage temp | −50°C to +150°C |
| Package | DO-201 (axial) |

## Board role

Reverse-polarity / freewheel protection in the DC input path — a standard
commodity part choice for this function.

## Lifecycle / sourcing status

Asian fabs.
